# M4 T-slot nut (Fairway JPPNM04016)

`t-slot-nut-m4.step`, built in `/tmp/fx/nut.py` style code with OpenCASCADE. Known: 15.87 × 11 × 3.14 mm, M4 (listed sizes). Estimated from a product photo only: rounded ends (full 5.5 mm radius), the hole 4.5 mm from one end (modelled at the 3.3 mm tap-drill size), and a dome 5 mm across and 0.5 mm high, 4.5 mm from the other end on the face toward the slot lip. The table model's slot is 3 mm deep inside, 0.14 mm less than the nut.

The same nut is now a part in the user's Fusion machine file (`T-Slot Nut - M4 (Fairway JPPNM04016)`, with a cosmetic M4 × 0.7 thread, minor diameter 3.242 mm) and is used by the Bookends, the vise and the Grid Plate. The bundled Bookends and vise models are exported from that file.
